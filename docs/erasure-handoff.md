# Measure install to first reviewed verdict

Use a disposable checkout of a participating team's own assistant. Recruit an engineer new to Setrya and a separate reviewer. Use the [paired benchmark scorecard](benchmark.md#record-the-session) for equal coding-agent access, help received, incorrect decisions and later voluntary reuse.

Start the wall clock immediately before the engineer installs Setrya. Record the first replayable verdict, including an inconclusive result, when its files become available. Record when the reviewer receives the bundle and when they correctly identify the target fact, retained fact, same conversation, worker outcome, and owner of each open item. Keep incorrect answers and elapsed time in the session. Enter these timezone-qualified ISO timestamps in the scorecard’s `erasure_timing` fields: `install_started`, `first_verdict`, `reviewer_received`, and `first_correct_review`. The report calculates install-to-first-verdict, install-to-first-correctly-reviewed-verdict, and independent review time from these timestamps. The targets are one hour for connection and two minutes for independent review. Receipt drill duration covers the live run alone.

On the team's next independently chosen summarizer, memory, cache, or worker change, record the new application commit, evidence location, deciding observation and whether anyone had to prompt the team. Record an explicit decline or unused opportunity as well. A scheduled benchmark rerun is an assigned exercise. The release includes an automated Graphiti comparison. Human onboarding and voluntary team reuse await participants.
